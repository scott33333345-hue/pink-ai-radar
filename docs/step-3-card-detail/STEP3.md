# 第 3 步：资讯卡片与详情页优化

完成日期：2026-10-17（Asia/Shanghai）

## 目标

让用户不只看到“发生了什么”，还能快速判断“为什么重要、影响谁、下一步做什么”，同时保持 Pink AI Radar 的轻盈编辑风格。

## 已完成

- 将等权卡片网格改为“今日必读 + 纵向编辑列表”。
- 为 7 条资讯增加事实摘要、状态、核验时间、为什么重要、影响对象和建议行动。
- 今日必读展示额外的影响判断和品牌配图。
- 详情页改为正文与判断侧栏双栏布局。
- 事实摘要、背景、编辑判断和来源证据被明确分区。
- “查看完整判断”和“查看官方原文”成为两个不同动作。
- 卡片支持 Enter 和空格键打开详情，原生 dialog 支持 Esc 关闭。
- 移动端将双栏详情重排为单栏，并隐藏导致导航拥挤的演示订阅按钮。
- 支持使用 `?news={id}` 直接打开指定资讯详情，便于分享和测试。

## 内容模型

每条资讯现在包含：

- 来源、发布时间、核验时间和发布状态；
- 标题与一句话摘要；
- 事实摘要与事件背景；
- 为什么重要；
- 影响对象；
- 建议行动；
- 主题标签、信源等级和原文链接。

## 当前限制

- 资讯仍保存在 `app.js`，数据解耦将在 D01 处理。
- 分类维度仍沿用旧版，F01/F02 将单独重构。
- 部分原文仍指向新闻首页或列表页，T01 将替换为精确来源。
- 当前只为今日必读配置一张正式配图，普通列表保持文字优先。
