# 第 16 步：性能与 SEO 优化

## 目标

让首页和每条正式简报都能被搜索引擎直接读取、被社交平台正确预览，并减少首批媒体资源的传输负担。

## 完成内容

### 1. 图片性能

- 将 `1672 × 941` 的 PNG 转换为 `1200 × 675` JPEG。
- 文件从 `1,642,296` 字节降至 `68,444` 字节，减少 `95.8%`。
- 保留 16:9 分享图比例，并在页面图片上声明宽高，降低布局位移风险。
- 首页列表图片使用延迟加载和异步解码。

原 PNG 已删除，但仍可从 Git 历史恢复。

### 2. 首页元信息

- 增加更明确的页面标题和描述。
- 增加 canonical、robots、主题色、Open Graph 与 Twitter Card。
- 增加 WebSite JSON-LD 结构化数据。

### 3. 独立资讯页

- 为 12 条正式简报生成 `news/{id}/index.html`。
- 每页包含可直接读取的事实摘要、背景、产品判断、行动建议与精确原文链接。
- 每页拥有独立 title、description、canonical、Open Graph 和 Article JSON-LD。
- 详情弹窗增加“打开独立阅读页”入口。

### 4. 搜索发现

- 新增 `robots.txt`。
- 新增包含首页和 12 条资讯的 `sitemap.xml`，共 13 个 URL。
- RSS 的 12 条链接改为对应独立阅读页，并使用永久链接 GUID。

### 5. 自动化

- `scripts/build-data.mjs` 现在同时生成网页数据、RSS、站点地图、robots 和独立阅读页。
- `scripts/check-seo.mjs` 检查首页元信息、12 个独立页、结构化数据、站点地图、RSS 链接和分享图体积预算。
- `npm run check` 已纳入 SEO 完整性检查。
