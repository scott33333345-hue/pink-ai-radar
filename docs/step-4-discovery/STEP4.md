# 第 4 步：重构分类、筛选和搜索

## 目标

帮助中文产品从业者从“浏览全部资讯”切换到“按决策问题快速定位资讯”。

## 已实现

- 将原先混合在一起的分类拆成主题、地区、时间三个独立维度。
- 主题包括：产品体验、模型能力、Agent、安全治理、开发者。
- 支持多维组合筛选，并实时显示结果数量。
- 搜索覆盖来源、状态、标题、摘要、事实、背景、重要性、标签、影响对象和行动建议。
- 将当前条件显示为可单独移除的标签，并提供“清除全部”。
- 增加无结果解释和“查看全部资讯”恢复操作。
- 搜索与筛选写入 URL，刷新或复制链接后可以恢复当前视图。
- 补充键盘焦点、`aria-pressed` 和动态结果播报。

## 时间口径

演示数据不是实时接口，因此“近 N 天”以当前数据集中最新一条资讯的发布日期为基准。接入真实数据后，应改为当前时间。
