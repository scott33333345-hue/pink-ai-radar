# 第 8 步：收藏与稍后阅读

## 目标

把一次性资讯浏览升级为可回访的个人阅读清单，让用户能保存对工作有价值的判断。

## 实现

- 卡片和详情页均可收藏或取消收藏。
- 收藏 ID 保存在浏览器 `localStorage`，键名为 `pink-ai-radar:saved-news`。
- “我的收藏”支持与关键词、主题、地区和时间条件组合筛选。
- 收藏筛选写入 URL 参数 `saved=1`，刷新后仍保持当前视图。
- 卡片、详情、数量和筛选状态使用同一份前端状态。
- 操作后显示可被辅助技术读取的状态反馈。
- 浏览器阻止本地存储时给出提示，不影响正常阅读。

## 验收标准

- 收藏后刷新页面，收藏状态仍保留。
- 卡片和详情页的收藏状态同步。
- 只看收藏时可继续搜索和筛选。
- 没有收藏或组合筛选无结果时显示针对性空状态。
- 收藏按钮支持键盘操作并暴露 `aria-pressed` 状态。

## 数据边界

收藏只保存在当前浏览器，不上传服务器、不跨设备同步，也不要求用户登录。
