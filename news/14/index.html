OpenAI Decisions API 正式开放，专门处理高频结构化判断

Decisions API 用 GPT-6 Luna 处理分类、选择和评分等边界明确的任务，支持文本、图像与 JSON，并面向低延迟、高频调用优化。

# 开发者# Agent# 产品

事实摘要

OpenAI 宣布 Decisions API 结束公测并正式开放。它支持 probability、choice 和 score 三类输出，单次最多可提交 400 个问题，并加入 GPT-Live、缓存和区域推理能力。

背景

许多 Agent 步骤并不需要生成长文本，只需要判断是否通过、选择下一步或给出评分；专用接口可以降低延迟、成本和输出不确定性。

为什么重要

AI 产品架构不必让同一个通用模型完成所有任务。把高频、边界明确的判断拆成专用能力，有助于提高稳定性和可测量性。

影响对象

  • AI 产品经理
  • Agent 开发团队
  • 风控与运营平台

建议行动

  • 识别流程中的高频封闭式判断
  • 用人工标准答案建立评测集
  • 设置低置信度转人工或通用模型的回退规则

来源与核验

A 级来源 · 官方原始来源 · 正式开放

OpenAI 官方产品页明确说明正式开放状态、输入输出类型、调用上限、价格与客户案例。
