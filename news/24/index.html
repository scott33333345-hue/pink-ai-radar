OpenAI 推出面向授权安全研究的 GPT-6-Cyber

GPT-6-Cyber 可用于漏洞调查、授权测试环境中的问题复现和修复验证，首次调用前需要完成 Daybreak 接入。

# 安全# 开发者# 治理

事实摘要

OpenAI API 更新日志显示，GPT-6-Cyber 于 11 月 5 日上线，可帮助获准用户调查漏洞、在授权测试环境中复现问题并验证修复；使用前需要按照 Daybreak 流程完成接入。

背景

网络安全模型可能同时具备防守和进攻价值，因此不能只依赖提示词限制。专业能力的开放通常还需要身份审核、场景授权、环境隔离和操作记录。

为什么重要

高风险 AI 产品的重点不只是模型能做什么，还包括谁能使用、可在哪些环境操作，以及如何追踪和阻断越界行为。

影响对象

  • 网络安全产品经理
  • 企业安全团队
  • AI 平台与治理负责人

建议行动

  • 为高风险能力设置准入与授权流程
  • 保留任务、工具调用和结果审计记录
  • 把漏洞复现限制在明确授权的测试环境

来源与核验

A 级来源 · 官方产品日志 · 受限开放

OpenAI 官方 API 更新日志明确给出模型上线时间、适用任务和 Daybreak 接入要求。
