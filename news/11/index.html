OOpenAI10 月 28 日合作扩展

OpenAI 与 ServiceNow 扩大合作，连接企业工作流与 Agent

双方将 ServiceNow 业务上下文和操作接入 ChatGPT 与 Codex；目前 MCP 插件已上线，语音、安全和 Codex 深度集成仍按计划逐步开放。

# 企业# Agent# 工作流

事实摘要

ServiceNow MCP 插件现已在 OpenAI marketplace 提供，增强能力预计在 2026 年底前推出；语音、安全和 Codex in AI Workflow Factory 分别计划在 2027 年分阶段开放。

背景

企业 AI 正从回答问题转向在既有系统中查找记录、评估风险和执行操作，权限继承、业务规则和可审计性因此成为关键产品能力。

为什么重要

合作公告常混合现有能力与未来路线。产品判断需要按功能拆分可用时间，避免把合作愿景写成已经交付的能力。

影响对象

  • 企业产品经理
  • IT 服务团队
  • 安全与自动化团队

建议行动

  • 区分现有插件与规划功能
  • 核对组织权限和操作边界
  • 从可回滚的低风险流程开始试点

来源与核验

A 级来源 · 官方原始来源 · 合作扩展

OpenAI 官方合作公告逐项列出现有能力、预览状态和计划时间，适合核对真实可用边界。
