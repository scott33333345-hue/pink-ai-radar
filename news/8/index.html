OOpenAI10 月 6 日合作发布

Atlassian 与 OpenAI 扩大合作，把企业知识接入 Agent 工作流

OpenAI 模型将进一步用于 Atlassian 平台和 Rovo，结合 Teamwork Graph 连接项目、文档、人员与决策。

# 企业# Agent# 工作流

事实摘要

OpenAI 与 Atlassian 宣布扩大合作：OpenAI 模型将支持 Atlassian 平台与 Rovo 中的 Agent，并通过 Teamwork Graph 使用企业上下文；更深层的 Jira Agent 集成仍处于探索阶段。

背景

企业 Agent 的价值依赖可访问的组织上下文、正确权限和可追踪执行，而不仅是通用模型能力。

为什么重要

产品经理可以把企业知识层视为 Agent 的基础设施，同时明确区分已上线能力和合作方正在探索的路线。

影响对象

  • 企业产品经理
  • Agent 平台团队
  • 研发效能团队

建议行动

  • 梳理高价值企业上下文和权限边界
  • 优先试点可审计的协作流程
  • 不要把探索中的集成当作现有功能

来源与核验

A 级来源 · 官方原始来源 · 合作发布

OpenAI 官方合作公告明确区分现有接入方式与仍在探索的后续集成。
