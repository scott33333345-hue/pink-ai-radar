Microsoft 发布 Copilot Harness，开放多模型 Agent 编排能力

Microsoft 将内部使用的多模型 Agent 编排层通过 Foundry 对外提供，覆盖模型选择、上下文、工具调用、执行环境和控制机制。

# Agent# 开发者# 企业

事实摘要

Microsoft 宣布通过 Microsoft Foundry 提供 Copilot Harness。该编排层已用于 Copilot Code、Copilot Studio、GitHub Copilot 应用、CLI 和 VS Code，并支持 MCP、Agent Skills 与插件。

背景

Agent 的稳定性不只取决于模型，还取决于模型路由、上下文管理、工具执行、权限控制和长期维护，这些能力正逐步从自建工程转为平台服务。

为什么重要

产品团队选型时应把模型和编排层分开评估，比较任务成功率、成本、可替换性与控制能力，而不是只追逐单一模型。

影响对象

  • Agent 产品经理
  • 企业开发团队
  • AI 平台负责人

建议行动

  • 列出业务所需的编排与控制能力
  • 用同一任务比较不同模型组合
  • 评估平台绑定和迁移成本

Microsoft 官方博客直接说明产品定位、现有使用范围、对外入口和支持的开放标准。
