OpenAI 发布 GPT-6.1 Terra，强化视觉理解与计算机操作

GPT-6.1 Terra 面向视觉理解、计算机操作和日常工作任务，在 API、ChatGPT Work 与 Codex 中提供更低成本的自动化选择。

# 模型# 产品# 开发者

事实摘要

OpenAI 发布 GPT-6.1 Terra，称其标准 API 价格比 GPT-5.6 Terra 和 GPT-6.1 Sol 低 50%，并重点提升视觉推理、计算机操作、写作与编码能力。

背景

计算机操作模型开始覆盖表单填写、文档处理、技术图纸理解和视频编辑等跨软件任务，模型价值越来越依赖执行稳定性和单位任务成本。

为什么重要

产品选型应从单次回答质量转向完整任务完成率、人工接管频率、延迟和成本，尤其要验证视觉定位与操作错误。

影响对象

  • AI 产品经理
  • 流程自动化团队
  • 应用开发者

建议行动

  • 选取真实桌面任务建立评测集
  • 记录失败步骤和人工接管次数
  • 按完整任务核算成本而非只看 token 单价

来源与核验

A 级来源 · 官方原始来源 · 模型发布

OpenAI 官方发布页说明模型定位、能力变化、价格和产品入口；性能比较按官方评测口径理解。
